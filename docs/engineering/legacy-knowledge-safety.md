# Legacy shared-knowledge পথের fail-closed পরিবর্তন

সম্পর্কিত পরিকল্পনা: [zero-cost-learning-plan.md](zero-cost-learning-plan.md)।

`ai_knowledge_exchange.py` ও `ingest_pr_knowledge.py` অনিরীক্ষিত legacy packet/envelope থেকে Supabase `knowledge_base`, `learned_facts` বা Qdrant-এ কোনো write/embedding করে না। Live ingestion চাওয়া হলে non-zero error; explicit `--dry-run` কেবল সীমিত validation, raw packet/diff না দেখিয়ে জানায় যে কিছু সংরক্ষণ/অনুমোদন করা হয়নি। GitHub source read ব্যর্থ বা অসম্পূর্ণ হলে সফল দেখায় না। পুরোনো `active` rows-এর briefing export-ও বন্ধ: row-এর status বা agent-এর নিজের পরিচয় independent approval নয়। `decision_records.py` এখনও read-only, fixed-vocabulary candidate তৈরি করে; সেটি storage, approval বা runtime sharing নয়।

এটি পুরোনো Supabase/Qdrant records বা backup মুছে দেয় না। #917 merge-এর পর main workflow-এর পুরোনো live invocation fail করেছে; নতুন workflow patch শুধু স্পষ্ট `--dry-run` validation চালায়, summary ও dispatch description-এ জানায় কিছু সংরক্ষণ বা অনুমোদন হয় না। Invalid evidence বা source read failure এখনও job ব্যর্থ করে; নিষ্ক্রিয় live writes/briefing bypass করা হয় না। এই workflow patch যাচাই ও merge/deploy না হওয়া পর্যন্ত production-এ কার্যকর নয়। স্বাধীন reviewer-controlled quarantine, immutable source ও revision, consent, approval/revocation audit, নিরাপদ পুনরুদ্ধার এবং frontend integration সম্পূর্ণ না হওয়া পর্যন্ত live sharing পুনরায় চালু করা যাবে না। UI, cross-conversation import, connected-AI import, live quality evaluation, সব auth path ও deletion propagation এখনও বাকি।

এই guard **সব learning path বন্ধ করে না**: `scripts/ci/kaggle_learning_bridge.py` এবং `core/api/routes/kaggle.py`-তে আলাদা active knowledge/fact ও vector write path রয়েছে; `core/memory/supabase_store.py`-তেও অন্য shared fact লেখার ও পড়ার পথ আছে। এগুলো এবং downstream consumers আলাদাভাবে audit ও নিয়ন্ত্রণ না করা পর্যন্ত সর্বব্যাপী quarantine বা isolation দাবি করা যাবে না। `ingest_pr_knowledge.py`-এর ingestion এখন diff আনে না, কিন্তু পৃথক `--query-pr` এখনও raw diff print এবং local archive তৈরি করতে পারে; `--query-file` পুরোনো Supabase metadata পড়তে পারে। এসব CLI-তে সংবেদনশীল repo/data ব্যবহার বন্ধ রেখে আলাদা privacy review প্রয়োজন; পুরোনো archive এ patch মোছে না।
