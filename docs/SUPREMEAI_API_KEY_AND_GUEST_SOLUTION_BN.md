# SupremeAI — Single API Key Execution Standard

1. **একক ও চূড়ান্ত নীতি:** সিস্টেম শুধুমাত্র এবং এককভাবে `SUPREMEAI_API_KEY` দিয়ে পরিচালিত হবে।
2. **জিরো থার্ড-পার্টি কী:** ব্যবহারকারী বা ক্লায়েন্ট কখনো Gemini, OpenAI বা অন্য কোনো থার্ড-পার্টি API Key ব্যবহার বা প্রদান করবে না; এর কোনো প্রয়োজন নেই।
3. **প্রোভাইডার ব্ল্যাকবক্স:** `supremeai-api` পেছনের কাজ কীভাবে সম্পন্ন করছে তা ক্লায়েন্টের দেখার বিষয় নয়; ক্লায়েন্টের একমাত্র বৈধ কারেন্সি হলো `SUPREMEAI_API_KEY`।
4. **গেস্ট অ্যাক্সেস:** ফ্রন্টএন্ড স্টুডিওতে সরাসরি ডিফল্ট `SUPREMEAI_API_KEY` ইনজেক্টেড থাকবে, যাতে কোনো ভিজিটরের কাছ থেকে আলাদা কি চাইতে না হয়।
5. **স্থায়ী নিষেধাজ্ঞা:** সিস্টেমে Gemini বা OpenAI-এর কোনো API Key চাওয়া বা বাধ্য করা সম্পূর্ণ নিষিদ্ধ।
